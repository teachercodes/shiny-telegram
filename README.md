# Mission Animaux — GitHub Pages

This is the complete static web app, ready for GitHub Pages.

1. Create a public repository named mission-animaux. Enable Add README.
2. Extract the ZIP. Upload its files and folders into the repository root.
   index.html must be directly in the root, beside app.js and styles.css.
   Keep assets/ and vendor/ as folders. Do not upload only the ZIP itself.
3. In Settings > Pages, choose Deploy from a branch.
4. Select main and / (root), then Save.
5. When deployment finishes, use the Visit site link in Settings > Pages.

The student website will be at:
https://YOUR-USERNAME.github.io/mission-animaux/

No GitHub or ChatGPT account is needed to visit the published website.

To set the Toddle destination, open Espace enseignant in the game,
paste your Toddle assignment URL, and copy the generated student link.
Students download their report and submit it themselves in Toddle.

Student answers are stored in the student's browser, not in this repository.

Official setup guide:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
